# Contributing

Changes must preserve the authority boundary in `docs/architecture.md`.

Do not add source parsing, build admission, image inspection, planning projection, application admission, target mutation, migration, or compatibility import to `libpkgstate`. Put a translation against another semantic owner in its role-qualified adapter repository.

A semantic change requires typed failure behavior, deterministic construction, identity and durable-record analysis, focused tests, documentation updates, and release-contract updates. Use C++17, the checked-in formatting policy, POSIX shell for contracts, and GPL-3.0-or-later SPDX headers.
