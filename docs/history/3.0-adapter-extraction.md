# 3.0 adapter extraction

The 2.5.1 repository built the state owner and four optional foreign-authority adapters in one project. That arrangement made one release, CI graph, option matrix, and fallback tree responsible for five independently changing semantic boundaries.

Version 3.0 extracts the four adapters without rewriting their implementation bodies. `libpkgstate` retains the durable state model, publication evidence and codec, compare-and-publish interface, canonical generation backend, and `pkgstate-check` diagnostic client.

The extraction changes repository ownership and dependency direction. It does not reinterpret generation-v3 records or state-owned identities.
