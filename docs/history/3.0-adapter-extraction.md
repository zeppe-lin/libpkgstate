# 3.0 adapter extraction

The 2.5.1 repository built the state owner and four optional foreign-authority adapters in one project. That arrangement made one release, CI graph, option matrix, and fallback tree responsible for five independently changing semantic boundaries.

Version 3.0 extracts the four foreign-authority adapters and the concrete generation-store provider without rewriting their semantic bodies. `libpkgstate` retains the durable state model, publication evidence and codec, and backend-neutral compare-and-publish interface.

The extraction changes repository ownership and dependency direction. `libpkgstate-posix` preserves the storage mechanism and diagnostics, but the 3.0 authority reset advances records to generation v4. `libpkgsource` 3.0 retired recipe identity, so the state source record and its canonical storage representation no longer carry that foreign field.
